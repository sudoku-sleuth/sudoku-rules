# Lying clues

Shipped: `liar-cells` assigns independent real values with group counts and
separate digit/value distinctness. `clue-count` owns an explicit list of typed
clue records and counts false complete meanings with exactly, at-least or
at-most. Each line, box or whole-grid scope is supplied explicitly. Nested
contracts, defaults and shared answer channels follow the referenced rule.

Remaining: alternatives for a mark's rule kind (`clue-choice`) and finite
semantic lowering for clue counts and shared value assignments. No
`clue-choice` declaration is accepted. See [Clue Count](../../rules/clue-count.md)
and [declarations](../../spec/declarations.md) for the shipped contracts.
