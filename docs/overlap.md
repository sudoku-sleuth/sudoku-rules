# Library overlap

The comparison expands predicate bodies to depth three, substitutes lets, normalises bound names, flattens associative operations and sorts commutative operations. Primitive identities and the domains of free parameters remain distinct. Subtree Jaccard similarity identifies related formulas; it does not establish equal meaning.

Run `bun run openrules overlap --min 0.35` for names, layers, scores and shared formula subtrees. Add `--json` for structured pairs, settings and reasons.

## Shared blocks

Two named rules binding the same block are related by design. The CLI lists them under “same block, different settings”, including differing binding expressions or parameter domains. These pairs are excluded from the overlap threshold. An identical instantiated formula always fails, including two rules binding the same block.

Outside retains repeated cell occurrences; Quadruple takes a cell set. Their input domains distinguish their formulas even when their binding expressions match.

## Cross-meaning distinctions

The allowlist contains only pairs whose shared structure expresses different operations or scopes. Stale entries fail the guard. A block consisting only of one predicate call fails as a wrapper.

| Pair | Reason |
| --- | --- |
| moveRelation / selectedPair | moveRelation selects a geometric move; selectedPair additionally selects all, incident or scoped pairs. |
| partition / connectedRegionPartition | partition requires disjoint nonempty coverage; connectedRegionPartition also requires connected regions. |
| selectedCells / marked | selectedCells constructs the set of marked cells; marked tests membership of one cell. |
| segmentSide / segmentCross | segmentSide returns an oriented numeric cross product; segmentCross tests a segment intersection. |
| markedStart / markedRun | markedStart tests only the beginning of an interval; markedRun requires a maximal marked interval. |
| operandSlice / operandBounds | operandSlice extracts the corresponding occurrences; operandBounds produces validated slice endpoints. |
| odd / classParity | odd tests whether that residue is one; classParity returns a residue. |
| read / channelValue | read obtains those arguments from a board cell; channelValue selects supplied face/effective numeric arguments. |
| window / cyclicCut | window selects a bounded window with optional wrapping; cyclicCut rotates a whole path. |
| reversal / decimal | reversal returns a reversed cell list; decimal evaluates a base-ten numeral. |

Liar Cells and Lying Clues own distinct formulas and require no overlap allowance. Counts use countWhere; distinctness uses allDifferent. The new clueHolds primitive supplies the complete truth of an owned clue.
