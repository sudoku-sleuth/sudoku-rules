BLACKCURRANTS: Cells connected by a blackcurrant have a 1:2 ratio (one is double the other.) Not all possible blackcurrants have been given.

CAGES: Digits don't repeat in a cage. Every cage has the same total, which is to be deduced. The digit on a cage's electricity symbol is its 'shock value'. Any cage with a shock value of 5 or more is switched on, and Finkz should not enter these for safety reasons. Cages with a shock value lower than 5 are switched off and therefore safe to enter.

TEST CONSTRAINT: In this experiment, the correct path will be a valid Chinese Whisper line, ie; adjacent digits along the path must differ by at most 2.
