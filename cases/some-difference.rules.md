0-8 Somedoku: Fill each cell with a digit from 0-8. For every row 'n' and column 'n' there are exactly 'n' unique digits. The remaining cells are filled with repeats.

Same Difference: Each pair of adjacent digits on a turquoise line contain the same difference. This difference must be determined for each turquoise line. If there is a diamond present, its digit indicates the difference value of the line. Not all possible diamonds are necessarily given.

Different Difference: No two pairs of adjacent digits anywhere on a peach line may have the same difference. Eg: if there is a 2 next to a 4 on a peach line, there can't be a 5 next to a 7 anywhere on the same line.

Note: A connected, branching line is considered to all be the same line.

Kropki: two digits joined by a black dot have a 1:2 ratio (one is double the other.)
