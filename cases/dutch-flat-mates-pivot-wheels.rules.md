Normal sudoku rules apply.

Every 5 in the grid must have a '1' directly above it or a '9' directly below it. It may have both, but it doesn't need both.

Digits in a wheel have to be placed in the same circular order in the four cells that are touched by the wheel. Wheels have to be rotated 90° clockwise N times from the current position, where N is the digit in the cell inside the wheel.
