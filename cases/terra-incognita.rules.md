- RBC 1-6 sudoku: Fill the grid with the digits from 1 to 6 and the letters R, B and C such that each row, column and 3x3 box/region contains each symbol once. If a cell contains an R, B, or C its value is the cell's row number (R), box number (B) or column number (C).  Rows, columns and boxes are numbered from top to bottom and left to right.

- Index Lines: Each turquoise line is an Index Line, i.e. the value of the Nth cell along such a line (starting from the diamond) indicates the position along the line where the value N appears. If a diamond has multiple lines, each line is treated separately.
For example, if a diamond cell has a value of 3, the third cell along that line must have a value of 1. (If allowed by other rules, symbols may repeat along a line.)

- Kropki: Cells joined by a white dot have consecutive values. (Not all dots are given.)
