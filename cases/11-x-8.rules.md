```rules
sudoku 9x9
cage-1: cage r1c1-r1c2-r2c1 total 11 connected true
cage-2: cage r3c3-r3c4-r4c3-r4c4 total 11 connected true
cage-3: cage r6c3-r6c4-r7c3-r7c4 total 11 connected true
cage-4: cage r6c6-r6c7-r7c6-r7c7 total 11 connected true
cage-5: cage r3c6-r3c7-r4c6-r4c7 total 11 connected true
cage-6: cage r8c1-r9c1-r9c2 total 11 connected true
cage-7: cage r8c9-r9c8-r9c9 total 11 connected true
cage-8: cage r1c8-r1c9-r2c9 total 11 connected true
anti-king
kropki-1: kropki r3c4-r4c4 white
kropki-2: kropki r6c6-r7c6 white
kropki-3: kropki r8c7-r8c8 black
whispers-1: whispers r8c6-r9c7 gap 5
whispers-2: whispers r8c4-r9c3 gap 5
whispers-3: whispers r5c1-r6c1-r5c2-r6c2 gap 5
whispers-4: whispers r3c8-r4c7-r4c8-r5c8-r6c8 gap 5
parity-cells r8c1 parity "odd"
```

Normal Sudoku rules apply.
Cells within a king's move (in chess) cannot contain the same digits.
Green lines are German Whispers lines. Adjacent digits along the line must differ in value by at least 5.
Digits in killer cages must sum to the value in the top left corner of the cage. Digits may not repeat within a cage.
White dots join cells with consecutive values. Black dots join cells with a value ratio of 2:1. Not all dots are given.
The cell with a gray circle contains an odd digit.
