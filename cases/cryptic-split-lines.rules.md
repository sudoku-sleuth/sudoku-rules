Fill the grid with the digits 1-9 so that digits don't repeat in any row or column.

Each digit is represented by a letter of the alphabet, to be determined.

Using these letters, the answer to each cryptic clue below can be placed into the grid in a straight line, reading from left to right or downwards. Each peach circle marks the start of at least one word, and each peach diamond marks the end of at least one word. Every word starts at a circle and ends at a diamond. Different words can not share more than one cell.

If a blue dot sits on a word, it divides that word into segments which each have the same sum when the letters are translated to digits.
