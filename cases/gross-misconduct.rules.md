Fill the grid with the digits 1-9, plus the letters R, B and C, so that no letter or digit repeats in any row, 3x4 box, or column.

3x4 boxes are numbered 1-12 in normal reading order.

The value of an R equals its row number.
The value of a B equals its box number.
The value of a C equals its column number.

BLACK KROPKI: If two values are joined by a black dot, one is double the other.

RENBAN: Values along a pink line form a non-repeating consecutive sequence, arranged in some order.

GERMAN WHISPER: Adjacent values on a green line have a difference of at least 5.

ARROWS: Values along an arrow sum to the value in the attached circle.

SAME DIFFERENCE: Adjacent values on a turquoise line have the same difference. This difference may be different for different turquoise lines.
