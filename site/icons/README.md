# Rule icons

The rule SVGs in `rules/` are original Sudoku Sleuth artwork, distributed under
this repository’s [MIT licence](../../LICENSE). Shape navigation icons remain
at the top level.

`rules.json` maps named-rule and reference-page slugs to the owned SVG assets. Each named rule keeps its familiar symbol; Extra Regions reuses the house symbol and XV the pair symbol. Blocks need no icon.

The SVGs are inlined beside names, hidden from screen readers and coloured with `currentColor` and the site theme tokens. The `killer` and `whisper` assets match `cage` and `whispers`.
